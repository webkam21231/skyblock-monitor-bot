# SkyBlock Monitor Bot

Telegram-бот для минутного мониторинга прогресса Hypixel SkyBlock.

## Возможности

- добавление нескольких Minecraft-аккаунтов и SkyBlock-профилей;
- снимки Mining/HOTM/commissions/powder/purse каждую минуту;
- единая кнопка отчёта сразу по всем добавленным аккаунтам;
- тёмные PNG-карточки с приростом для одного или всех аккаунтов;
- отчёты за 15/30 минут, 1/3/6/12/24 часа, 7/30 дней;
- произвольный период с точностью до минуты;
- предупреждение, когда Mining XP растёт, а комиссии стоят;
- топливо и инвентарь намеренно не отслеживаются.

## Важное ограничение commissions

Официальный Hypixel API сейчас отдаёт счётчик `skyblock_hard_working_miner` на уровне Minecraft-аккаунта, а не отдельного SkyBlock-профиля. Бот использует его для точных изменений количества выполненных commissions. Если один Minecraft-аккаунт выполняет commissions на нескольких профилях, изменения будут суммарными.

Powder в отчётах — доступный (непотраченный) powder из официального API. Трата powder на дерево может дать отрицательную дельту, даже если за период powder добывался.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
cp .env.example .env
# заполнить TELEGRAM_BOT_TOKEN и HYPIXEL_API_KEY
set -a; . ./.env; set +a
.venv/bin/skyblock-monitor
```

Секреты хранятся только в `.env`, который исключён из Git.

## Произвольный период

Формат времени — МСК:

```text
04.09.2026 18:30 - 04.09.2026 21:45
```

Для отчёта нужны минимум два сохранённых снимка внутри выбранного периода.

## Проверка
